# Algorithm Explorer (v1)

A browser playground for five algorithms. No install. No build step. No packages.

Open `index.html` in a browser and switch sections with the top buttons.

## How to start

**Easiest:** in Finder, double-click

`my_work/algorithm-explorer/index.html`

or drag that file onto Chrome / Safari / Firefox.

**From Terminal** (optional):

```bash
cd my_work/algorithm-explorer
python3 -m http.server 8766
```

Then open: [http://127.0.0.1:8766/](http://127.0.0.1:8766/)

Stop the server with Control-C.

## Dependencies

None. HTML, CSS, and JavaScript in the browser (Canvas 2D). No Node, npm, or Python required unless you use the local server above.
