# 在 Blender 里拧这个罐子

形体是几何节点算的。几何节点是挂在物体上的一小段程序：点还是原来缝好的那些，程序只改它们的位置。

1. 打开 `jar.blend`（不进 git）。物体名 **Jar**。
2. 选中 Jar。右侧属性里找到修改器 **揉搓弯折**。滑条按组排好：形体、揉搓、拇指、弯折、口沿、泥。
3. 要看程序本身：上方工作区切到 **Geometry Nodes**。外面那一层叫「揉搓弯折」，负责壁厚和底盘。里面那一块叫「外表」，是母线、褶、扭转和口沿。外表被用了三次，用来算出壁往哪一面厚。

拖滑条，视口里的罐子会跟着变。`output/object.stl` 不会自动跟着变。改完要导出，跟我说一声。

周向多少段、竖向多少段不在滑条里。那是点的数量，改了就要重跑 `build_jar.py`，不是拖一下能变的。

不要在 Blender 里 Boolean 挖坑或裁切。褶再深，内腔半径也不会小于「内腔最小半径」。再往上加，面可能自己穿过去，导出检查会失败。
