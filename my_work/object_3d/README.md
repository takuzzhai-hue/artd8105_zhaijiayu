# 揉过的罐子 — kneaded jar

外轮廓不是圆罐子加细槽。它是一小片泥：母线给出罐子的肚子和脖子，然后同一片壁被褶、三处拇指、扭转、侧推和起伏的口沿一起搬走。内壁跟着走，壁厚还在。网格仍是固定拓扑缝合，不用 boolean、不用裁切。

滑条在 Blender 修改器 **揉搓弯折** 上。怎么打开，见 `GEOMETRY_NODES.md`。

## 规则

**母线** `R0(z)`：脚、腹、颈、口四个半径。

**揉搓** 绕一圈的软褶，加上三处拇指（负是按进去，正是挤出来），再在脖子下方收一下腰。种子把这一圈转开。

**弯折** 从底到口扭转一个角度，口再被推离中轴。底还坐在平面上。

**口沿** 高低起伏，不是一刀切平的圆口。

壁厚是沿着表面法线留出来的，不是只在半径上减一刀。褶变陡的时候，半径相减会把壁削薄；沿法线退一截，捏的是整片泥。再深也有一个下限：内腔半径不会小于「内腔最小半径」。

单位：1 STL 单位 = 1 mm。身子高 160 mm。口沿还会再抬起来，所以包围盒比 160 高一截。壁 4 mm，底 3.6 mm。

这一组默认的褶深、扭转和口沿，是对照两张参考暂定的：软的褶和起伏的口来自陶瓷那件，拧和侧推来自金属那件。金属的棱面和尖顶没有做。哪一项该改，是你的设计决定，滑条就是干这个的。

## 跑一次

```bash
cd my_work/object_3d
source .venv/bin/activate   # 若还没有：python3 -m venv .venv && pip install -r requirements.txt
./run.sh
```

`run.sh` 先 `generate.py`（网格自检通过才写文件），再 `check_stl.py`（不读 bpy，从字节重验）。这写出的是滑条在默认位置的罐子。打印用 `output/jar.3mf`，单位已经写死是毫米。`object.stl` 是同一只模型。

Blender 里拖过滑条之后，视口变了，`object.stl` 不会自动变。要导出新的，跟我说一声。

## 滑条

都在修改器 **揉搓弯折** 里。

| 组 | 滑条 | 默认在干什么 |
|---|---|---|
| 形体 | 高度、脚 / 腹 / 颈 / 口半径，腹和颈的位置 | 罐子曲线。默认脚 28、腹 52、颈 34、口 46，高 160 |
| 揉搓 | 褶数、褶深、杂乱、收腰、种子、拇指宽度和高低 | 三道软褶，深 9 mm，腰再勒 4.5 mm |
| 拇指 | 三处的角度、高度、深浅 | 两处按进去，一处挤出来 |
| 弯折 | 扭转、弯折、弯折方向 | 从底到口转 120°，口被推开 22 mm |
| 口沿 | 起伏、瓣数、过渡 | 口沿高低差 10 mm |
| 泥 | 壁厚、内腔最小半径 | 4 mm，洞不小于半径 14 mm |

## 校验

**写出前**（`generate.py`）：非流形边 = 0，边界边 = 0，连通分量 = 1，V−E+F = 2，有符号体积 > 0，最薄壁 ≥ 1.6 mm。失败则报错退出，不写 STL。

**写出后**（`check_stl.py`）：自己解析 STL 字节。三角数、包围盒、有符号体积、每条边恰好被两面反向共享、union-find 壳体数、射线壁厚。不用 bpy。

**Blender 3D-Print Toolbox**：按 `CHECK_BLENDER.md`。不要在 Blender 里修完再覆盖 `object.stl`。

当前默认一次（`output/verification_report.md`）：三角形 61056，χ = 2，壳体 1，有符号体积 > 0，包围盒约 114.7 × 108.6 × 170.9 mm，射线壁厚 min 3.647 mm。
